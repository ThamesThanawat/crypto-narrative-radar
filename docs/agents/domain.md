# Domain and Shared Language

This repository uses CONTEXT.md as the source of truth for project language.

Before planning, debugging, writing documentation, or generating recruiter-facing explanations, read:

CONTEXT.md

## Canonical Project Framing

Crypto Narrative Radar is a Python-based crypto market intelligence and research support project.

It is not:

- a trading bot
- a price prediction model
- a buy/sell signal generator
- a portfolio optimizer
- a backtesting engine

## Canonical Terms

Use these terms consistently:

- Token Universe
- Primary Narrative
- Secondary Narratives
- Market Snapshot
- Narrative Metrics
- Narrative Ranking
- Narrative Momentum Score
- Price Momentum
- Relative Strength
- Volume Confirmation
- Breadth of Participation
- Concentration Review
- Token Contributors
- Data Quality Flag

## Language Rules

Use cautious research language:

- narrative momentum increased
- relative strength improved
- volume confirmation strengthened
- breadth expanded
- participation narrowed
- the move appears concentrated
- this may warrant deeper research

Avoid trading language:

- buy
- sell
- guaranteed upside
- alpha signal
- price prediction
- this will pump
- profitable strategy

## ADR Rule

Use docs/adr/ only for important technical decisions that are:

1. hard to reverse,
2. surprising without context,
3. the result of a real tradeoff.
