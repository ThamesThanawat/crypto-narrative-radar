Methodology

Crypto Narrative Radar uses a manually reviewed narrative taxonomy, CoinGecko market data, token-level market snapshots, and narrative-level aggregation to create a descriptive research view.

Narrative Momentum Score is a relative research ranking score, not statistical confidence. Small score gaps should be interpreted cautiously.

The Narrative Momentum Score uses the current V1 framework: 40% price momentum, 25% relative strength, 20% volume confirmation, and 15% breadth of participation.

  • 40% Price momentum: 24h, 7D, and 30D median return context.
  • 25% Relative strength: 7D median return compared with BTC and ETH.
  • 20% Volume confirmation: Volume-to-market-cap activity context.
  • 15% Breadth of participation: Share of tokens participating across return windows.

Component scores are percentile-rank normalized within the current narrative universe using the existing pandas rank percentile method.

Relative Strength 7D averages median narrative 7D return minus BTC 7D return and median narrative 7D return minus ETH 7D return.

Concentration labels and comments are judgment-based V1 heuristics, not statistically derived cutoffs.

Return skew diagnostics are descriptive only. Skew and dispersion review thresholds are judgment-based V1 review heuristics, not statistically derived cutoffs. The IQR threshold is snapshot-relative: each narrative's 7D return IQR is compared with two times the median narrative 7D return IQR in the same report snapshot, not an absolute cross-date threshold. These diagnostics do not affect the Narrative Momentum Score. The review flag does not imply an investment recommendation.

The token universe is 80 manually curated tokens: 10 representative tokens per narrative, not full sector coverage.

Taxonomy assignments involve judgment and can miss sector breadth or token overlap.

DuckDB SQL analytics outputs support narrative summaries, token-level contributors, and concentration context. Historical narrative data, when available, is used only as descriptive trend context.

The score is a research ranking tool for market intelligence. It does not imply future returns.
